## 本次调整

针对此前画笔拖动期间长时间不刷新、最后才显示完整笔触的问题，本版恢复使用 0.23 的画笔与画布基础，只移植独立缓存液化。画笔引擎、栅格存储、原生输入与应用入口保持 0.23 实现。

液化直接作为画布工具使用，固定在工具栏的画笔、橡皮、涂抹之后。选中后，顶部选项栏提供液化子工具、图层范围、大小与硬度；不再打开旧液化弹窗。

液化交互时，原始像素、位移场、冻结信息和预览输出保留在 GPU 缓存中。预览使用独立显示缓存，避免普通画布刷新覆盖液化结果；拖动中显示变形，松手保留预览。

- 范围支持图层、图层组、全部图层，默认全部图层。
- 支持液化会话内撤销、重做。
- Enter 或切换工具提交为一次文档历史；Escape 取消本次液化。
- 提交失败时保留当前缓存编辑，避免静默丢失结果。

打包 App 使用正常用户偏好、Metal 和 Low-Latency Drawing，在 6000×4000 画布上抓到按下和两次移动时的实际笔触画面。两次移动控制请求耗时为 46.42 / 42.37 ms；这些数值是控制请求往返时间，不代表物理笔输入到屏幕显示的延迟。用户随后实际操作并反馈“基本好了”。

## 遗留问题与交付边界

1. **菜单入口仍有残留。** 菜单目录中的液化条目已删除，但引擎命令的菜单元数据仍会自动生成 Filter → Liquify 入口，因此“不在菜单中选择”尚未完全落实。独立工具和无弹窗使用方式已可用。
2. **复杂组样式预览存在一致性风险。** 父图层组的样式形状仍来自原始 CPU 子层，液化实时预览可能与提交后的组样式不同。
3. **旋转视图叠加不完整。** 冻结蒙版和网格叠加目前仅在未旋转视图绘制。
4. **基线验证有未通过项。** 两个旧平滑测试仍期待平滑效果，而 0.23 的 `Brush::bounded_for_render` 明确关闭旧平滑功能；本版保留该实现。严格 Clippy 仍被原有 `brush_sections.rs` 的 `parameter` 参数过多阻断。
5. **源码标签与现有 App 版本须区分。** 本次 GitHub 标签和源码版本为 0.23.5；此前已验证的本地 App 仍标识 0.23.0，未重新编译为 0.23.5。该 App 为 Apple Silicon、本地 ad-hoc 签名，未 notarized；本次未交付新的 Windows、Intel 或其他平台安装包。现有发布工作流只匹配 `0.23` 标签，`0.23.5` 不会触发它。

## 清理与保留

功能源码已提交，并保留在主源码目录 `code/` 的 `liquify-on-023` 分支。清理阶段删除约 11 GiB 构建缓存及临时实施脚本，保留当前 App、正在使用的画布、用户偏好和验证记录；未覆盖用户后续操作产生的设置。
